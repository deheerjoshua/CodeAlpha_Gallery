 Image Gallery - CodeAlpha Task 1

A responsive Image Gallery with filter, search, and lightbox - built for CodeAlpha Internship.

 Features
- Filter by category (Nature, City, Tech, Food)
- Search images by title
- Lightbox view - click any image to view full size
- Next / Previous buttons in lightbox
- Hover effect with caption
- Responsive design - works on phone & computer

Tech Used
- HTML
- CSS
- JavaScript
